# Clip Links Inbox

Drop one link per line in `links.txt` (or any `.txt` file here).

Supported:
- X / Twitter: https://x.com/user/status/123...
- YouTube: https://www.youtube.com/watch?v=...
- Direct .mp4 URLs

The pipeline reads these first. If the file is empty, it falls back to search.

Example:
```
https://x.com/example/status/1234567890
https://www.youtube.com/watch?v=dQw4w9WgXcQ
```
