# Songs Bank

Put original `.mp3` files here. Name them with mood so the code can pick:

- `dark_*.mp3`
- `emotional_*.mp3`
- `aggressive_*.mp3`
- `romance_*.mp3`
- `epic_*.mp3`

The pipeline prefers a matching mood file from this folder.  
If none match, it falls back to YouTube (PO Token + cookies).

**Note:** Do not commit copyrighted tracks to the public repo.  
Upload your licensed/original mp3s to the `songs-bank` GitHub Release or keep them local.
