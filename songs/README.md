# Songs Bank (Royalty-Free / CC)

Mood-named `.mp3` files for the pipeline.

Current tracks (from Internet Archive — free to use):
- epic_* — action, trailer, heroes, adventure
- aggressive_* — chase, battle, aggression
- dark_* — tension, panic, golem
- romance_* / emotional_* — softer cinematic

The code picks by mood prefix matching the genre.

**Note:** These are royalty-free / Creative Commons tracks, not commercial chart hits.
For licensed original commercial songs, upload your own mp3s here (or to the songs-bank release) with the same mood naming.
